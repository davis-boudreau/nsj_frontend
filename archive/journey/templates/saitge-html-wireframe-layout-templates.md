### Common HTML layout templates that you can use for your web pages:

### 1. Single Column Layout
A simple layout with one column, often used for mobile-first designs.

```html
<div class="single-column">
    <p>Content goes here</p>
</div>
```

### 2. Two Column Layout
A layout with two columns, typically used for sidebars and main content.

```html
<div class="two-column">
    <div class="column-left">
        <p>Left column content</p>
    </div>
    <div class="column-right">
        <p>Right column content</p>
    </div>
</div>
```

### 3. Three Column Layout
A layout with three columns, useful for more complex designs.

```html
<div class="three-column">
    <div class="column-left">
        <p>Left column content</p>
    </div>
    <div class="column-center">
        <p>Center column content</p>
    </div>
    <div class="column-right">
        <p>Right column content</p>
    </div>
</div>
```

### 4. Header and Footer Layout
A layout with a header, main content area, and footer.

```html
<div class="header">
    <p>Header content</p>
</div>
<div class="main-content">
    <p>Main content goes here</p>
</div>
<div class="footer">
    <p>Footer content</p>
</div>
```

### 5. Grid Layout
A flexible layout using CSS Grid for more complex designs.

```html
<div class="grid-container">
    <div class="grid-item">Item 1</div>
    <div class="grid-item">Item 2</div>
    <div class="grid-item">Item 3</div>
    <div class="grid-item">Item 4</div>
</div>
`` Flexbox Layout
A layout using Flexbox for responsive designs.

```html
<div class="flex-container">
    <div class="flex-item">Item 1</div>
    <div class="flex-item">Item 2</div>
    <div class="flex-item">Item 3</div>
</div>
```

### 7. Sidebar Layout
A layout with a sidebar and main content area.

```html
<div class="sidebar-layout">
    <div class="sidebar">
        <p>Sidebar content</p>
    </div>
    <div class="main-content">
        <p>Main content goes here</p>
    </div>
</div>
`` 8. Full-Screen Layout
A layout that covers the entire screen, often used for landing pages.

```html
<div class="full-screen">
    <p>Full-screen content</p>
</div>
```
